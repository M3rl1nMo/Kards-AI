# 开发日志

## 2026-10-09：模拟器训练接口与 DILEMMA 修复

### 本次完成

- BUG-01～02：DILEMMA 使用目标单位执行交换，清除旧设置费用记录，修复重复交换读取旧值的问题。
- BUG-03：最后一次换牌结束后切回 p1 并启动首回合；自动路径不再重复启动。自动和手动保留起手牌的状态一致。
- BUG-04：终局奖励采用行动方视角，胜利 +100、失败 -100、平局不增加终局奖励；保留原有对手总部掉血奖励。
- BUG-05：修正动作选项条件表达式，避免高攻击力单位导致其他卡牌的选项丢失。
- BUG-06：玩家观测补充己方反制措施、费用规则、单位修正与状态；对方秘密保持隐藏。
- BUG-07：观测单位编号不包含卡名；新增 get_player_actions()/step_player()，动作与观测使用一致编号。原始动作接口保留给裁判层使用。
- BUG-08：默认严格检查未支持效果，触发后抛出异常、整局无效并禁止继续；异常报告包含种子、初始状态、动作及事件，供调试重现。未补齐所有卡牌效果。
- 修复 resolver 条件检查误用静态方法却访问 self.cards 的问题。
- BUG-09：按用户确认的规则，设置费用与增减独立生效；交换读取当前费用，新设置基准扣除已有增减以避免重复叠加，保留修正来源。
- 添加中文 BUG 注释、问题说明文档和回归测试，更新 README 的换牌与测试覆盖说明。

### 验证

- BUG-01～08 完成后，英国/德国简单固定卡组经玩家动作接口运行 100 局，10,359 个动作、373 次 DILEMMA 使用；全部终局，无未支持效果或交换数值错误。
- BUG-09 完成后，220 项单元测试全部通过，无预期失败；没有重新宣称上述批量对局是 BUG-09 后的测试结果。
- BUG-09 定向结果（攻击力/行动费用）：4/0 → 交换 0/4 → 费用 +1 得 0/5 → 再交换 5/0；费用 -1 得 0/3 → 再交换 3/0。
- 同时验证攻击增减、交换前已有费用修正、连续交换、来源记录保留与最新设置值生效。
